# Агентская командная аналитика российского инвестиционного рынка  
*(AI‑команда для MOEX)*

*Профессиональная аналитика для вашего портфеля — без лишних усилий*

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## О проекте

**Проблема:** частному инвестору сложно самостоятельно проводить всесторонний анализ рынка. Макроэкономика, новости, фундаментальные и технические индикаторы, налоговые последствия — всё это требует времени, знаний и доступа к дорогим инструментам.

**Решение:** автономная команда AI-агентов, которая работает как собственный аналитический отдел. Вы задаёте вопрос — агенты распределяют задачи, собирают данные, запускают скрипты, проверяют результаты и выдают готовый отчёт.

Проект ориентирован на **частных инвесторов**, которые хотят принимать осознанные решения без погружения в рутину.

## Возможности

- **Анализ текущего портфеля** — оценка структуры, рисков, доходности, дивидендов.
- **Составление нового портфеля** — подбор инструментов под заданные цели.
- **Консультации по отдельным продуктам** — акции, облигации, ETF на MOEX.
- **Генерация инвестиционных идей** — на основе макросводок и рыночной конъюнктуры.
- **Технический анализ** — автоматический расчёт индикаторов и интерпретация сигналов.
- **Налоговый расчёт** — оценка налоговых последствий сделок.
- **Контроль качества** — QA-агент проверяет итоговый отчёт на ошибки.

## Архитектура

В центре системы — **координатор**, который получает запрос пользователя и запускает конвейер обработки.  
Все этапы выполняются агентами и детерминированными скриптами, LLM используется только там, где нужен интеллектуальный анализ.

```
Пользовательский запрос
        │
        ▼
  Координатор (pipeline.ts)
        │
        ├─► Извлечение тикеров (ticker-extractor-worker)
        ├─► Нормализация инструментов (lookup_instruments)
        ├─► Макроэкономический анализ (macro + cbr_data, cbr_survey)
        ├─► Генерация идей (rnd-worker)
        ├─► Новостной анализ (news-worker)
        ├─► Фундаментальный анализ (fundamental-worker)
        ├─► Технический анализ (technical + analyze_stock.py)
        ├─► Анализ облигаций (bond-worker)
        ├─► Анализ ETF (etf-worker)
        ├─► Портфельный анализ (portfolio-worker)
        ├─► Налоговый анализ (tax-worker)
        ├─► Сборка отчёта (summary-worker)
        └─► QA-проверка (qa-worker)
                │
                ▼
        Итоговый отчёт (99_final_report.md)
```

Каждый агент — это `.md`-файл с инструкцией. Расширения на TypeScript обеспечивают взаимодействие с MOEX API, запуск Python‑скриптов и оркестрацию.

## Быстрый старт

### Требования
- [VS Code](https://code.visualstudio.com/) с [Dev Containers](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers) (рекомендуется для изоляции агентов от локальной ОС)
- [Docker](https://docs.docker.com/get-docker/)

### Установка
1. **Клонируйте репозиторий** и откройте его в VS Code:
   ```bash
   git clone https://github.com/yourname/russian-market-analytics.git
   code russian-market-analytics
   ```

2. **Настройте модели** — скопируйте `.devcontainer/pi-home/models.example.json` в `.devcontainer/pi-home/models.json` и заполните его своими LLM‑моделями. Подробнее: [документация Pi по моделям](https://pi.dev/docs/latest/models).

3. **Настройте параметры** — скопируйте `.devcontainer/pi-home/settings.example.json` в `.devcontainer/pi-home/settings.json` и укажите нужные пути. Подробнее: [документация Pi по настройкам](https://pi.dev/docs/latest/settings).

4. **Запустите Dev Container** — нажмите `F1` в VS Code, выберите **Dev Containers: Reopen in Container**.  
   Контейнер автоматически:
   - установит Node.js, Python и необходимые пакеты;
   - примонтирует ваши `models.json` и `settings.json`;
   - выполнит скрипт `post-create.sh`, который установит `pi-coding-agent`, плагины и Python‑зависимости.

5. **Запустите Pi** — откройте терминал в VS Code и выполните:
   ```bash
   pi
   ```
   После запуска агент‑координатор готов принимать запросы.

## Пример использования

Запрос к агенту:

```
Выгодно ли покупать сейчас акции SBER?
```

Агент запускает полный цикл: макрообзор, новости, фундаментальный и технический анализ, налоговые последствия — и возвращает отчёт.

## Пример отчёта (фрагмент)

```markdown
# Инвестиционный отчёт

## Резюме
Макроэкономическая ситуация характеризуется высокой ключевой ставкой **14.5%** 
и инфляцией **5.58%**. Рынок ожидает снижения ставки во II полугодии.

## Сводка рекомендаций
- Акции: SBER, VTBR
- Облигации: SU26238RMFS5
- ETF: AKFB

## План сделок (из портфельного аналитика)
- Увеличить долю облигаций до 60%
- Сократить акции до 30%, оставив 10% в золоте

## Налоговые последствия
При ребалансировке возможна фиксация убытка по акциям, 
что уменьшит налогооблагаемую базу на **12 400 руб.**
```

## Технологический стек

| Компонент | Назначение |
|-----------|------------|
| [Pi Coding Agent](https://github.com/earendil-works/pi) | Платформа для запуска AI‑агентов |
| Docker / devcontainers | Изолированная среда выполнения |
| Python | Cкрипты для работы с MOEX, ЦБ РФ |
| TypeScript | Расширения и оркестрация агентов |
| LLM (любые) | Интеллектуальный анализ (чем качественнее модель, тем точнее выводы) |
