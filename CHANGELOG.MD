# Changelog

## 2026-06-24: Переход на Exa API для поиска, расширение источников макро-данных

### Новые инструменты поиска и чтения веб-страниц

Полностью заменён поисковый стек. Вместо нестабильного DuckDuckGo Lite и ограниченного `pi-search-hub` реализованы собственные инструменты, зарегистрированные в расширении:

- **`web_search`** через Exa MCP API (бесплатный, без ключа)
- **`web_read`** через прямой скраппинг страниц с BeautifulSoup

Реализация:
- **`tools/web_search.py`** — поиск через `mcp.exa.ai/mcp` с инициализацией MCP-сессии, парсингом SSE-ответов и извлечением полей `title`, `url`, `snippet` из блока `Highlights`
- **`tools/web_read.py`** — загрузка и очистка HTML: удаление скриптов, стилей, навигации, рекламы; извлечение текста с базовым Markdown-форматированием; ограничение 8000 символов
- **`web-tools.ts`** — регистрация `web_search` и `web_read` как инструментов расширения через `execAsync`

### Расширение макро-скрипта государственного долга

Скрипт `fetch_cbr_extdebt.py` полностью переписан и переназнан в **`fetch_government_debt.py`**. Теперь собирает данные из трёх источников:

1. **Внешний долг РФ** — `cbr.ru/statistics/macro_itm/external_sector/ed/ext-debt/` (текст из `div.landing-text`)
2. **Внутренний долг РФ** — `minfin.gov.ru/ru/opendata/7710168360-DomesticDebt/7710168360-DomesticDebt-visual/` (таблица из `div.opendata_data`)
3. **Фонд национального благосостояния** — `minfin.gov.ru/opendata/7710168360-NationalWealthFund/7710168360-NationalWealthFund-visual/` (последние 5 строк таблицы)

Все значения конвертируются из тысяч рублей в миллиарды рублей для читаемости.

### Обновление macro.ts

В `getMacroContext()` добавлен вызов `fetch_government_debt.py`. Результат (`extDebtData`) передаётся в промпт макро-воркеров, что позволяет budget-агенту получать актуальные данные по госдолгу и ФНБ без поиска на недоступном `minfin.gov.ru`.

### Правка russian-macro-worker.md

Добавлено правило для недоступных официальных источников: разрешается использовать данные Интерфакса, РБК, Ведомостей, Коммерсантъ, ТАСС с указанием первоисточника, если официальный сайт недоступен после 2 попыток.

## 2026-06-22 (макро-агенты): Завершение аудита макро-воркеров второго прогона

Проведён анализ логов всех четырёх макро-агентов второго тестового прогона. Выявлена системная проблема с доступом к официальному сайту Минфина (503 ошибки), из-за которой budget-агент потратил много попыток на поиск данных по госдолгу.

### Правка в russian-macro-worker.md
- Добавлено правило для недоступных официальных источников: «Если официальный источник недоступен после 2 попыток (ошибки 403, 503, таймаут), разрешается использовать данные авторитетных финансовых изданий: Интерфакс, РБК, Ведомости, Коммерсантъ, ТАСС, которые прямо цитируют официальный источник. В этом случае укажи первоисточник данных в формате: "INTERFAX, со ссылкой на Минфин"».

### Результаты работы агентов

**monetary-агент:** отработал чисто — использовал только переданные таблицы, без web_search, корректно разграничил факт/прогноз. Расхождение ставок ровно 0.5 п.п. — верно не стал бить тревогу (>0.5).

**budget-агент:** столкнулся с недоступностью minfin.gov.ru (503), но в итоге корректно использовал данные Интерфакса и Вестей со ссылкой на Минфин. Самостоятельно рассчитал проценты доходов/расходов от ВВП. Единственное замечание — формат отчёта не соответствует промпту (разные единицы измерения), но агент работал в условиях ограниченной доступности источников.

**balance-агент:** использовал переданные таблицы и статистику Банка России без лишних поисков. Все показатели с фактом и прогнозом, корректное предупреждение об отклонении курса USD/RUB с пояснением причин.

**gdp-агент:** отработал чисто — только переданные таблицы, без web_search, корректное разграничение факт/прогноз, отметил отклонение курса USD/RUB более чем на 6% с пояснением.

### Общие улучшения по сравнению с первым прогоном
- Все агенты соблюдают разграничение «факт» / «текущее значение» / «прогноз»
- Нет дублирования одной цифры под разными названиями
- Нет поиска данных, которые уже есть в переданных таблицах
- Предупреждения о расхождении курсов валют с пояснениями причин

## 2026-06-22 (вторая волна): Аудит второго тестового прогона и пакетные правки

Проведён сквозной анализ второго тестового прогона на запросе «Составь мне портфель для стабильного роста без частых вмешательств на 50000 рублей». Выявлены проблемы: использование нереалистичных цен из RND вместо приоритетных источников, нарушение запрета `ls -R`, перепутывание ETF с фьючерсами, неверное описание налоговой льготы ЛДВ.

### Ключевое изменение: переход новостей на smart-lab.ru

Новостной модуль полностью переведён с web_search/web_read на парсинг smart-lab.ru:
- **Новый скрипт `tools/fetch_smartlab_news.py`**: ищет новости через три источника последовательно (форум `/forum/news/TICKER/`, поиск `/search/topics/`, поиск только по имени). Парсит даты, заголовки, ссылки.
- **Переписан `news.ts`**: больше не вызывает агентов-воркеров, напрямую запускает скрипт, парсит JSON и формирует Markdown-отчёт с экранированием спецсимволов.
- **`russian-news-worker.md`** оставлен как заглушка (не используется, но сохранён для истории).

### Исправление классификации ETF в lookup

- **`fetch_moex_etf.py`**: добавлены поля `name`, `shortname`, `instr_id`. Добавлен запасной поиск на доске TQBR для ETF с проверкой INSTRID.
- **`lookup.ts`**: `checkStock` теперь возвращает `null` для инструментов с `INSTRID !== "EQIN"` (ETF и ПИФы больше не попадают в акции). `checkEtf` использует `name` из скрипта. Приоритет типов в `pickBest` изменён на `etf > stock > bond`.

### Правки промптов агентов

**russian-rnd-worker.md:**
- Добавлен запрет на `ls -R` и `ls` — читать файлы только через `cat`.
- Добавлены критерии нереалистичности цен: >20% для акций, >100₽ для ETF.
- Уточнение для ETF: цена в рублях за пай (обычно 1-50₽), не путать с фьючерсами.
- URL в плане действий должен быть реально открытой страницей, не шаблонной.
- Добавлена проверка дивидендной доходности через web_search.

**russian-technical-worker.md:**
- Добавлен запрет на запоздалые рекомендации: не ПРОДАВАТЬ, если цена уже ниже поддержки >3%, не ПОКУПАТЬ, если цена выше сопротивления >3%.
- Добавлен учёт RSI: не ПРОДАВАТЬ при RSI < 30, не ПОКУПАТЬ при RSI > 70.

**russian-portfolio-worker.md:**
- Ужесточён приоритет цен: первым делом проверять `fundamental_summary.md`.
- Добавлена проверка цены ETF: если >100₽ — проверять через web_search.

**russian-tax-worker.md:**
- Исправлено описание ЛДВ: «полное освобождение от НДФЛ при владении ≥ 3 лет» вместо ошибочного «до 3 000 000 руб.».

### Обнаруженные ошибки второго прогона (исправлены описанными выше правками)

- **RND-агент:** сгенерировал цены без проверки через web_read (GAZP 168.5₽ при реальной 104.49₽, SBER 210₽ при 312.84₽, TMOS 1100₽ за «контракт» при реальной цене пая ~5₽); использовал `ls -R`.
- **Портфельный аналитик:** использовал цены из RND вместо фундаментального анализа; не отметил противоречие с техническим анализом (ПРОДАВАТЬ); распределил доли поровну без учёта фундаментальных показателей.
- **Технический аналитик:** рекомендовал ПРОДАВАТЬ при текущей цене уже ниже поддержки (GAZP 104.49₽ при поддержке 109.71₽).
- **Налоговый аналитик:** скопировал ошибочное описание ЛДВ из примера в промпте.
- **Summary-воркер:** записал TMOS в раздел «Акции», дублировал ошибочное описание ЛДВ.

## 2026-06-18 — Исправления по результатам анализа отчётов агентов

### macro
- Добавлена проверка консистентности ключевой ставки и RUONIA: если разница > 0.5 п.п., агент выводит предупреждение.
- Агент различает прогнозные и фактические данные: значения на 2026+ годы из таблицы ЦБ помечаются как «прогноз» или «ожидается».

### rnd
- Ужесточены требования к подтверждению тикеров и цен: каждая цена должна быть проверена через `web_read`, а не только через сниппет `web_search`.
- Запрещено предлагать ETF, не торгуемые на MOEX (FinEx закрыт с 2022).
- Если цена не найдена или нереалистична, агент обязан отказаться от идеи и выбрать другую бумагу.

### news
- Ограничено количество поисковых запросов до 3 на один тикер (max_turns = 30).
- Для облигаций воркер сразу переключается на поиск по эмитенту, а не ищет новости по тикеру облигации.
- Запрещено читать через `web_read` страницы, не являющиеся новостными статьями.

### fundamental
- Агент использует последнюю строку CSV как актуальную цену закрытия.
- Приоритет данных: ltm → последний год → более ранние.
- При отрицательной чистой прибыли выводится оценка «компания убыточна, мультипликаторы неприменимы», а не «переоценена/недооценена».

### technical

- Убрана выдуманная дата «30‑06 2026 г.» — заменена на «за последние дни» при отсутствии точной даты.

### bond
- Если YTM = 0% при ключевой ставке > 10%, агент определяет облигацию как структурную (ИОС) и добавляет соответствующие риски.
