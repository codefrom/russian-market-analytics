# Changelog

## 2026-06-18: Полный аудит пилотного запуска и пакетные правки промптов

Проведён сквозной анализ работы всех агентов на тестовом запросе «Составь мне портфель для стабильного роста без частых вмешательств на 50000 рублей». Выявлены системные проблемы: нарушения формата вывода, игнорирование приоритета источников, отсутствие проверок согласованности данных, логические противоречия между агентами.

### Внесённые изменения

**russian-macro-worker.md:**
- Добавлено жёсткое правило проверять переданные таблицы перед любым web_search.
- Введено разграничение «факт» / «текущее значение» / «прогноз» с запретом называть текущие данные «фактом за год».
- Добавлена расшифровка формата таблицы прогнозов ЦБ (числа в скобках — предыдущий прогноз).
- Ужесточено требование пояснять расхождение текущего курса со среднегодовым прогнозом при отклонении >3%.
- Добавлен запрет дублирования одной цифры под разными названиями.

**russian-rnd-worker.md:**
- Добавлено требование диверсификации по классам активов (акции, облигации, ETF).
- Исправлен пример источника цены: заглушка `[источник цены]` заменена на требование указывать реальный URL.

**russian-news-worker.md:**
- Добавлен фильтр новостей: игнорировать кадровые назначения и персональные санкции.
- Введено предпочтение первоисточников (Интерфакс, РБК, Коммерсантъ, Reuters, ТАСС) перед агрегаторами.
- Добавлено требование указывать, если новость касается дочерней компании, а не самого эмитента.

**russian-fundamental-worker.md:**
- Добавлен обязательный пересчёт дивидендной доходности от актуальной цены из CSV, а не использование готового процента из LTM.
- Чистый долг теперь выводится отдельной строкой, если EBITDA отсутствует.
- Добавлено предупреждение о размерности (млрд руб.) с примером расчёта.
- Добавлена проверка нулевого дивиденда через web_search.

**russian-technical-worker.md:**
- Запрещено выдумывать промежуточные ценовые уровни (вход, цель) — только на основе поддержки/сопротивления из `analyze_stock.py`.
- Добавлено правило: цель должна быть достижима от текущей цены (для ПОКУПАТЬ — выше, для ПРОДАВАТЬ — ниже).
- Добавлено обязательное поле «Текущая цена» в формате отчёта и требование указывать её в рекомендации.

**russian-portfolio-worker.md:**
- Усилен запрет на `ls -R` и `ls`: первое действие всегда — чтение файлов через `cat`.
- Запрещено предлагать покупку актива, если технический анализ рекомендует ПРОДАВАТЬ.
- При противоречии фундаментального и технического анализа требуется отмечать разногласие в отчёте.
- Добавлена формула HHI с примером расчёта.
- Введено требование диверсификации с облигациями (минимум 20-30% для стабильного роста).
- В формате сделок добавлено поле «новостной фон».

**russian-qa-worker.md:**
- Добавлено правило: для запросов «составить портфель» появление новых тикеров — норма, не ошибка.
- Для запросов «проанализировать портфель» отсутствие перечисленных тикеров — ошибка.

**summary-worker.md:**
- Добавлен явный запрет на использование `ls` и `ls -R`.
- В раздел «Риски» добавлено обязательное указание противоречий между рекомендациями.

### Исправление форматирования во всех промптах

## 2026-06-18 — Исправления по результатам анализа отчётов агентов

### macro
- Добавлена проверка консистентности ключевой ставки и RUONIA: если разница > 0.5 п.п., агент выводит предупреждение.
- Агент различает прогнозные и фактические данные: значения на 2026+ годы из таблицы ЦБ помечаются как «прогноз» или «ожидается».

### rnd
- Ужесточены требования к подтверждению тикеров и цен: каждая цена должна быть проверена через `web_read`, а не только через сниппет `web_search`.
- Запрещено предлагать ETF, не торгуемые на MOEX (FinEx закрыт с 2022).
- Если цена не найдена или нереалистична, агент обязан отказаться от идеи и выбрать другую бумагу.

### news
- Ограничено количество поисковых запросов до 3 на один тикер (max_turns = 30).
- Для облигаций воркер сразу переключается на поиск по эмитенту, а не ищет новости по тикеру облигации.
- Запрещено читать через `web_read` страницы, не являющиеся новостными статьями.

### fundamental
- Агент использует последнюю строку CSV как актуальную цену закрытия.
- Приоритет данных: ltm → последний год → более ранние.
- При отрицательной чистой прибыли выводится оценка «компания убыточна, мультипликаторы неприменимы», а не «переоценена/недооценена».
- Добавлен расчёт долга: если доступны EV и Капитализация, вычисляется чистый долг и Долг/EBITDA.
- Убрана передача отдельной currentPrice (агент берёт из CSV).

### technical
- Добавлена проверка логичности стоп‑лосса: для покупки — ниже поддержки, для продажи — выше сопротивления.
- Запрещено дублировать заголовок `## TICKER`, если он уже присутствует в выводе скрипта `analyze_stock.py`.
- Убрана выдуманная дата «30‑06 2026 г.» — заменена на «за последние дни» при отсутствии точной даты.

### bond
- Если YTM = 0% при ключевой ставке > 10%, агент определяет облигацию как структурную (ИОС) и добавляет соответствующие риски.
- Для структурных облигаций запрещено писать «привлекательная доходность» или «надёжный инструмент».

### portfolio
- Запрещено использовать `ls -R`; разрешено читать только конкретные файлы через `cat`.
- Введён приоритет источников цен: fundamental → technical → web_search → rnd.
- Цены из RND проверяются: при расхождении с другими источниками > 20% отбрасываются.
- Для каждой сделки требуется указывать источник цены.

### tax
- Запрещено использовать `ls -R`.
- Добавлена прогрессивная шкала НДФЛ (13%, 15%, 18%, 20%, 22%), вступившая в силу с 2025 года.
- Агент проверяет актуальные ставки через `web_search`.

### qa
- Исправлена логика проверки: наличие в отчёте тикеров, не указанных в запросе, **не считается ошибкой**, если пользователь просил «составить портфель».
- Ошибкой считается только отсутствие тикеров при запросе «проанализировать существующий портфель».

### pipeline
- `lookup_results.json` и `warnings.md` теперь записываются один раз после сбора всех инструментов (первый lookup + интерактивный ввод + извлечение из RND).
- Новостные элементы (`newsItems`) формируются с полями `name` и `type` из `foundInstruments`.
